---
title: "Dialog"
description: "Dialogs display content that temporarily blocks interactions with the main view. Use them sparingly and only when necessary."
---

Dialogs focus attention on a task or decision before returning to the main UI.

Catalyst Core does not ship a `cat-dialog` web component. If you use **Catalyst Angular**, use `CatDialogService` and `DialogComponent` from that package.

## Angular

Refer to the Catalyst Angular documentation for opening, configuring, and closing dialogs (size, focus trap, and actions).

## Web components / other frameworks

Use native `<dialog>`, your framework’s modal primitives, or Catalyst layout components until a Core dialog is available.
