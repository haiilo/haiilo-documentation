---
title: "Menu"
description: "A menu component that provides a dropdown with a built-in configurable trigger button and proper ARIA semantics and keyboard navigation for menu items. The trigger is always a button with sensible defaults but fully configurable through trigger-specific props."
---

```html preview
<cat-menu>
  <cat-menu-item>Inbox</cat-menu-item>
  <cat-menu-item>Archive</cat-menu-item>
</cat-menu>
```

## Examples

### Basic menu

```html preview
<cat-menu>
  <cat-menu-item icon="inbox">Inbox</cat-menu-item>
  <cat-menu-item icon="archive-outlined">Archive</cat-menu-item>
  <cat-menu-item icon="trash-outlined" color="danger">Trash</cat-menu-item>
</cat-menu>
```
