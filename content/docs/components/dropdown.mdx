---
title: "Dropdown"
description: "A dropdown component to display a list of actions in a dropdown menu or to show additional content on demand."
---

```html preview
<cat-dropdown>
  <cat-button slot="trigger" data-trigger>Menu</cat-button>
  <div slot="content" class="cat-p-m">Dropdown content.</div>
</cat-dropdown>
```

## Examples

### Menu dropdown

```html preview
<cat-dropdown>
  <cat-button slot="trigger" data-trigger icon="menu-outlined">Menu</cat-button>
  <nav slot="content">
    <ul>
      <li><cat-button class="cat-nav-item">Profile</cat-button></li>
      <li><cat-button class="cat-nav-item">Settings</cat-button></li>
      <li><cat-button class="cat-nav-item" color="danger">Logout</cat-button></li>
    </ul>
  </nav>
</cat-dropdown>
```

### Placement

```html preview
<cat-dropdown placement="bottom-end">
  <cat-button slot="trigger" data-trigger icon="more-vertical-outlined" icon-only a11y-label="More options"></cat-button>
  <div slot="content" class="cat-p-m">Custom dropdown content.</div>
</cat-dropdown>
```
