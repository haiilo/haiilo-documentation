---
title: "Menu Item"
description: "A menu item component that renders as a button with proper ARIA semantics."
---

```html preview
<cat-menu-item>Label</cat-menu-item>
```

## Examples

### Menu item

```html preview
<cat-menu>
  <cat-menu-item icon="user-outlined">Profile</cat-menu-item>
  <cat-menu-item icon="settings-outlined">Settings</cat-menu-item>
  <cat-menu-item icon="logout-outlined" color="danger">Logout</cat-menu-item>
</cat-menu>
```
