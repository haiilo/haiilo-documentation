## Examples

### Basic tabs

```html preview
<cat-tabs active-tab="tab1">
  <cat-tab id="tab1" label="Overview"></cat-tab>
  <cat-tab id="tab2" label="Details"></cat-tab>
  <cat-tab id="tab3" label="Settings"></cat-tab>
</cat-tabs>
```

### Tabs with icons

```html preview
<cat-tabs active-tab="home">
  <cat-tab id="home" label="Home" icon="home-outlined"></cat-tab>
  <cat-tab id="search" label="Search" icon="search-outlined"></cat-tab>
  <cat-tab id="profile" label="Profile" icon="user-outlined"></cat-tab>
</cat-tabs>
```
